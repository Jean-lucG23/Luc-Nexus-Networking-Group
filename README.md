# Luc Nexus Networking Group — Website

This package is a deployment-ready responsive static website matching the supplied Luc Nexus Networking Group visual direction.

## Included
- `index.html` — complete website, content and SEO structure
- `styles.css` — responsive dark navy / blue design
- `script.js` — mobile navigation and WhatsApp consultation form
- `assets/luc-nexus-logo-transparent.png` — newly supplied transparent-background logo

## Deployment
Upload the contents of this package to your hosting provider's public web directory (often `public_html` on cPanel), keeping the `assets` folder beside `index.html`.

This works with ordinary static hosting such as cPanel/shared hosting, Netlify, Vercel, GitHub Pages, Cloudflare Pages and similar providers.

## Form
The consultation form is frontend-only and opens WhatsApp with the completed enquiry. This means no database or server is required for the basic site.

For automatic email/database storage later, connect the form to your preferred form backend or API.

## Before publishing
- Replace any placeholder social-media links (`href="#"`) with the actual company profiles.
- Add your final domain to canonical/Open Graph metadata if you use a custom domain.
- Add your Privacy Policy and Terms & Conditions pages.
- If desired, add Google Search Console, analytics and a Google Business Profile.
